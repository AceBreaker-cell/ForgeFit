# Start ForgeFit

**Try it on Windows:** install Java 17 or 21, then double-click `run-windows.cmd`. Wait for the server to start and open http://localhost:8080. Choose **Create account**.

**Develop in IntelliJ:** open `pom.xml` as a Maven project, choose JDK 17 or 21, and run `ForgeFitApplication.java`. Keep the working directory set to the project root.

**Try it on Linux:** run `chmod +x run-linux.sh mvnw`, then `./run-linux.sh`.

The `runtime/` folder contains the tested application snapshot. After editing source code, run through IntelliJ/Maven or rebuild the JAR; the snapshot does not update itself.

Read `README.md` for the full guide. `docs/MOBILE.md` explains phone access. `docs/PORTFOLIO.md` explains GitHub setup. `docs/VERIFICATION.md` lists tested behavior and remaining checks.

Use a separate demo account if you choose **Add sample data**.
